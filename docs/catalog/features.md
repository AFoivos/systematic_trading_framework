# Κατάλογος Features

Τελευταία ενημέρωση: 2026-07-31

Τα features περιγράφουν πληροφορία διαθέσιμη τη στιγμή της απόφασης: απόδοση, τάση, μεταβλητότητα, κύκλο, market structure, ροή και regime. Δεν είναι labels και δεν επιτρέπεται να ενσωματώνουν μελλοντικά bars.

Ο κατάλογος συνδέεται απευθείας με τα registries: κάθε ενεργό όνομα του κώδικα έχει ξεχωριστή αναλυτική ενότητα, ερμηνεία τιμών, χρονικό συμβόλαιο και πλήρες YAML. Τα ονόματα κώδικα, οι στήλες και οι YAML τιμές παραμένουν στα αγγλικά για να αντιγράφονται αυτούσια· όλο το επεξηγηματικό κείμενο είναι ελληνικό.

Στα YAML, `<required>` σημαίνει υποχρεωτική τιμή που πρέπει να αντικατασταθεί και `<configured>` επιλογή χωρίς ασφαλή καθολική προεπιλογή. Το `null` σημαίνει ότι η λειτουργία είναι προαιρετική ή ότι ο υπολογιστής θα επιλέξει το προεπιλεγμένο όνομα/συμπεριφορά.

## Ενεργά features

### `returns`

**Τι μετρά και τι πληροφορία δίνει.** Μετρά τη μεταβολή της τιμής κλεισίματος από bar σε bar, ως απλή ή λογαριθμική απόδοση. Θετική τιμή δηλώνει άνοδο, αρνητική πτώση και το απόλυτο μέγεθος εκφράζει την ένταση της κίνησης· αποτελεί βασική είσοδο για μεταβλητότητα, ορμή και μοντέλα πρόβλεψης.

**Είσοδοι και έξοδοι.** Το βήμα feature δηλώνει τις στήλες εισόδου και τα παραμετροποιήσιμα ονόματα εξόδου μέσω των τις σταθερές προεπιλογές του υπολογιστή. Η προηγούμενη παράγραφος εξηγεί την οικονομική σημασία της εξόδου, ενώ το YAML δείχνει τα ακριβή ονόματα στηλών που διαβάζονται ή γράφονται. Όλες οι παράμετροι, μαζί με τις προεπιλογές και τις υποχρεωτικές τιμές, εμφανίζονται παρακάτω.

**Χρονική ορθότητα και αποφυγή διαρροής.** Ο υπολογισμός είναι χρονικά συνεπής και επιτρέπεται να διαβάζει μόνο την κλεισμένη ράβδο `t` και παλαιότερες ράβδους. Όταν το feature χρησιμοποιείται για απόφαση στο `t`, η εκτέλεση πρέπει να γίνεται στην επόμενη εκτελέσιμη ράβδο, εκτός αν το πείραμα ορίζει αυστηρότερη υστέρηση.

**Παράμετροι.** Οι παράμετροι του contract είναι: με προεπιλογή `log`, `col_name`.

**Πλήρες YAML παράδειγμα:**

```yaml

- step: returns
  params:
    log: false
    col_name: null
```
